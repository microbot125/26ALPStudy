# push.pop 연산 복원

## 풀이 과정

1부터 n까지 순서대로 숫자를 push

현재 목표값이 아직 push하지 않은 값이면 해당 값까지 push

스택의 top이 목표값과 같으면 pop

top이 목표값보다 크면 목표값을 꺼낼 수 없으므로 NO 출력

push/pop 연산을 저장해두었다가 가능한 수열일 경우 출력

## 실수

- 크기가 0인 vector에 인덱스로 접근하려 함
- 반복문의 i를 push 값으로 활용하려던 기존 아이디어를 폐기하는 과정에서 vector 인덱스 순회의 범위를 잘못 잡음
- 불가능 조건에서 부등호 방향 반대
- size 함수의 반환형 때문에 int 변수와 비교 시 warning 발생

## 개선점

- 수열 전체를 vector에 저장하지 않고 입력받은 목표값을 바로 처리할 수 있음
- flag 없이 불가능한 경우 바로 종료하도록 단순화 가능
- 인덱스가 필요 없는 결과 출력은 range-based for로 순회 가능
- 스택이 비어 있는 경우를 별도로 처리하지 않아도 되도록 push 조건을 단순화할 수 있음

## 참고

- 인덱스가 필요 없는 vector 순회는 범위 기반 순회가 나음
- size 함수의 반환형은 size_t
