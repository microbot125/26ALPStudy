# 요세푸스 문제

## 풀이 과정
원형 연결 리스트에 1부터 N까지 저장

현재 위치를 첫 번째로 세므로 k - 1칸 이동한 뒤 해당 원소를 출력하고 삭제

## 실수
- 처음에 cpp의 리스트 라이브러리가 원형 구조가 아니라는 점을 고려하지 않고 ++it만으로 순회
- 마지막 원소를 삭제하면 erase()가 end()를 반환한다는 점을 고려하지 않음
- 테스트출력 구조화 누락 (<, > 빼먹음, ", "가 마지막 원소 출력 후에도 발생)

## 참고
- std::list는 양방향 연결 리스트이며 원형 연결 리스트가 아님
- list.erase(it)는 삭제한 원소의 다음 iterator를 반환
- end()는 실제 원소를 가리키지 않으므로 역참조하거나 증가시키면 안 됨
